# 🔐 Analizador de Fortaleza de Contraseñas

Herramienta de línea de comandos (CLI) desarrollada en Python que analiza la fortaleza de una contraseña y brinda recomendaciones de seguridad personalizadas.

Proyecto desarrollado como parte de las Prácticas Profesionalizantes – 6° año Técnico en Computación.

---

## ✅ Funcionalidades

- Analiza longitud, mayúsculas, minúsculas, números y símbolos
- Detecta contraseñas comunes y extremadamente débiles
- Asigna un puntaje de 0 a 7 y un nivel de fortaleza
- Brinda recomendaciones específicas para mejorar la contraseña
- Permite analizar múltiples contraseñas en una misma sesión

---

## 🛠️ Tecnologías utilizadas

- Python 3.13
- Módulo `re` (expresiones regulares, incluido en Python)
- Git & GitHub

---

## ▶️ Cómo ejecutar el programa

1. Cloná el repositorio o descargá el archivo `analizador.py`
2. Abrí una terminal en la carpeta donde está el archivo
3. Ejecutá el siguiente comando:

```bash
python analizador.py
```

4. Ingresá una contraseña cuando el programa lo solicite
5. Para salir, escribí `salir`

---

## 📊 Niveles de fortaleza

| Puntaje | Nivel |
|--------|-------|
| 0 – 1  | 🔴 MUY DÉBIL |
| 2 – 3  | 🟠 DÉBIL |
| 4 – 5  | 🟡 MODERADA |
| 6      | 🟢 FUERTE |
| 7      | 💪 MUY FUERTE |
